# etch-a-sketch: <a href="https://danielle-higgins.github.io/etch-a-sketch/" target="_blank">Visit Here</a>

<img src="https://github.com/Danielle-Higgins/etch-a-sketch/blob/main/img/preview.png">

Do you remember the etch a sketch toy when you were a kid? Well here is a web version of that very toy! Your able to draw whatever you want on the screen. Other features include clearing the screen, changing the size of the grid, and changing the pen color. Go wild and be an artist!
